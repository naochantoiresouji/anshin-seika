# パラメータ設定根拠（PARAMETERS）

本ドキュメントでは、`anshin_seika_sim.py`（v1.0）におけるデフォルトパラメータおよび検証ケースの設定根拠を定義する。

## 1. パラメータ一覧

| パラメータ名 | 変数名 | デフォルト値 | 概要 |
| :--- | :--- | :--- | :--- |
| チケット定価 | `ticket_price` | 10,000円 | 一次販売における基準価格 |
| 想定転売価格 | `resale_price` | 30,000円 | 二次流通市場における取引価格（定価の3倍） |
| プラットフォーム手数料率 | `fee_rate` | 10% (`0.10`) | 二次流通プラットフォームの販売手数料 |
| トークン発行料 | `token_cost` | 200円 / 口 | 応募時に発生するJPKI/ZKP発行手数料（返金不可） |
| 自前枠上限 | `free_slots` | 2口 | 調達コスト0円で確保可能な口数上限 |
| 名義調達コスト | `id_procurement_cost` | 3,000円 / 口 | 自前枠を超えた分の1口あたり外部調達コスト |
| 当選確率 | `win_rate` | 15% (`0.15`) | 基準ケースにおける当選確率（実質倍率 約6.7倍） |

---

## 2. 各パラメータの設定根拠

### 2.1 名義調達コスト（`id_procurement_cost = 3,000円`）

* **親族・知人枠における規模拡大（スケール）の限界**
  * 親族等の無料または低コストで協力が得られる枠（2〜4口程度）は絶対数が限られるため、1枚あたりの利益率が高くとも利益総額が小さく、事業としての採算が成立しにくい構造にある。
  * 応募口数を数十〜100口規模へ拡大するには、対人関係のリスクや個別説明の工数が大きい知人・遠縁への依頼ではなく、SNSやクラウドソーシング等を通じた不特定多数への外部委託（認証代行の募集）へ移行する必要がある。
* **認証代行の市場相場および操作ハードルとの整合性**
  * 一般的な代行業務の相場は、手続きの煩雑さと名義貸与に伴う心理的リスクに応じて段階的に形成されている（簡易なSMS認証代行は500円〜1,500円程度、決済や本人確認を伴う購入代行は1,000円〜3,000円程度、高リスクな口座・回線契約の代行は5,000円以上）。
  * 公的個人認証（JPKI）では、マイナンバーカードの物理的な読み取りと6桁以上の署名用パスワード入力が必要となるため、簡易なSMS認証よりも高い心理的・物理的ハードルが生じる。これらを踏まえ、単発スポット募集における現実的な最低報酬ラインとして `3,000円` を基準値に設定した。
* **募集・管理に伴う運用ロス（間接コスト）の包含**
  * 不特定多数へ外部委託を行う場合、報酬の支払い以外にも、操作手順の案内工数や、当選後の連絡途絶・手続き不履行といった運用上の損失（不良債権化リスク）が一定割合で発生する。これらを含めた実質的な1口あたりの調達単価として `3,000円` は妥当な下限値とみなせる。
* **シミュレーションにおける中立性の担保**
  * デフォルト条件（定価10,000円・二次流通価格30,000円・手数料10%・当選確率20%）における損益分岐上限は約3,130円であり、`3,000円` は大量応募側がわずかに黒字を維持できる水準に位置する。
  * 過大なコストを設定して意図的に赤字を演出するのではなく、外部委託による大量応募が成立し得る現実的な下限コストを基準として検証を行うための設定である。

### 2.2 自前枠上限（`free_slots = 2口`）
* 一般的な個人または世帯（本人＋同居家族1名）が、外部への報酬支払いや募集工数を伴わずに即時確保できる現実的な標準値として `2口` を設定した。
* なお、知人・親族の協力により自前枠が3〜4口程度まで増えた場合でも、数十〜100口規模の大量応募においては損益分岐点への影響は軽微となる。

### 2.3 トークン発行料（`token_cost = 200円`）
* 公的個人認証（JPKI）の電子証明書有効性確認に伴うプラットフォーム側への実費負担（数十円〜100円台）およびシステム維持費を賄いつつ、一般消費者（1〜2口応募）の参加意欲を阻害しない上限水準として `200円` を設定した。

### 2.4 価格・手数料・当選確率の設定
* **チケット定価・想定転売価格（`10,000円` / `30,000円`）：** ライブ・イベント等の標準的なチケット価格帯（1万円前後）と、人気公演の二次流通における代表的な取引水準（定価の3倍）を基準とした。
* **プラットフォーム手数料率（`10%`）：** 主要なチケット二次流通サイトやフリマアプリにおける一般的な販売手数料（8〜12%前後）の中央値として `10%` を採用した。
* **当選確率（`20%` 〜 `5%` / 基準 `15%`）：** 一般的な人気公演（倍率5〜7倍程度）を基準とし、より競争率の高いプレミア公演（倍率10〜20倍）までの変動を検証範囲とした。
